# Quantitative Writing

Use these rules when reporting measurements, experimental results, comparisons, or statistical findings.

- State the observed pattern and a suitably rounded magnitude.
- Do not describe a difference within expected noise as an improvement.
- Keep detailed values, intervals, and standard deviations in tables when several figures matter.
- Report differences consistently as points, percentages, or another clearly named unit.
- Keep units and signs consistent across prose, tables, and captions.
- Limit captions to what the display shows.
